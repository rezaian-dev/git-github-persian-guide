<h2><span class="hx"><span class="hx-t">🧪 پروژه ۲ — فیچر با PR و تعارض عمدی</span></span></h2>
<ol>
<li>شاخه <code>feat/hello</code> از main</li>
<li>فایل <code>hello.md</code> را تغییر بده، PR باز کن (Draft)</li>
<li>روی main همان فایل را جور دیگر عوض کن و push کن (با PR جدا یا مستقیم اگر آزمایش شخصی است)</li>
<li>تعارض را در <strong>VS Code Merge Editor</strong> حل کن</li>
<li>CI حداقلی (حتی <code>echo ok</code>) بگذار تا Check سبز شود</li>
<li>Squash merge</li>
</ol>
<p>معیار: اسکرین شات Merge Editor در README کارگاه.</p>
<h2><span class="hx"><span class="hx-t">🧪 پروژه ۳ — accidental secret و نجات</span></span></h2>
<ol>
<li>عمداً <code>.env</code> را کامیت کن</li>
<li>Push protection اگر گرفت، آفرین — دورش نزن</li>
<li>اگر نگرفت: <code>rm --cached</code>، gitignore، <strong>توکن ساختگی را rotate فرض کن</strong></li>
<li>توضیح بده چرا filter-repo لازم می‌شد اگر توکن واقعی بود</li>
</ol>
<div class="callout callout-warn"><div class="callout-title">هرگز توکن واقعی تمرین نکن</div>
<p>فقط مقدار <code>SECRET=fake</code> .</p>
</div>
