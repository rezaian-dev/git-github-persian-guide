<li>commitlint را در ذهن داشته باشی (پیاده در فصل ۲۵)</li>

</ul>

[body]

[footer]
</pre></div>
<p class="keep-next">انواع استاندارد: <code>feat</code>، <code>fix</code>، <code>docs</code>، <code>style</code>، <code>refactor</code>، <code>perf</code>، <code>test</code>، <code>build</code>، <code>ci</code>، <code>chore</code>، <code>revert</code>.</p>
<div class="code"><div class="code-head"><span class="dots"><i></i><i></i><i></i></span><span class="fname">نمونه‌ها</span></div><pre>feat(auth): add rotating refresh tokens

<p class="keep-next">Semantic Release:</p>
<ul>
<li><code>fix</code> → PATCH (1.2.3 → 1.2.4)</li>
<li><code>feat</code> → MINOR (1.2.3 → 1.3.0)</li>
<li><code>!</code> یا BREAKING CHANGE → MAJOR (1.2.3 → 2.0.0)</li>
</ul>
