1a:T220a,<p class="lead">در این فصل یک پوشه را به مخزن Git تبدیل می‌کنی، دو کامیت با پیام روشن می‌نویسی، و با <code>log</code> می‌بینی تاریخچه دقیقاً چه شکلی شده.</p>
  <h2><span class="hx"><span class="hx-t">🎯 اهداف یادگیری</span></span></h2>
<ul>
<li>مخزن را از صفر با <code>git init</code> یا از VS Code بسازی</li>
<li>پیام کامیت خوب بنویسی</li>
<li><code>log</code> را با گراف بخوانی</li>
<li>تفاوت <code>--allow-empty</code> و کامیت واقعی را بدانی</li>
</ul>
<h2><span class="hx"><span class="hx-t">🚀 ساخت مخزن</span></span></h2>
<h3><span class="hx"><span class="hx-t">روش ۱ — ترمینال (پایه)</span></span></h3>

<p>پرچم <code>-b main</code> شاخهٔ پیش‌فرض را <code>master</code> نمی‌گذارد. اگر فراموش کردی: <code>git config --global init.defaultBranch main</code>.</p>
<h3><span class="hx"><span class="hx-t">روش ۲ — VS Code (توصیهٔ این کتاب)</span></span></h3>
<ol>
<li>پوشه را با <em>File → Open Folder</em> باز کن</li>
<li>نوار کناری آیکون Git را بزن (<code>Ctrl+Shift+G</code>)</li>
<li>دکمهٔ <strong>Initialize Repository</strong></li>
<li>فایل بساز، در Changes ظاهر می‌شود</li>
<li>پیام را بنویس و <code>Ctrl+Enter</code></li>
</ol>
<p>اگر پنل خالی دیدی و دکمهٔ Initialize نبود، یا پوشه Git ندارد یا Git در PATH نیست.</p>
<h2><span class="hx"><span class="hx-t">✍️ پیام کامیت — قرارداد این کتاب</span></span></h2>
<p class="keep-next">از <strong>Conventional Commits</strong> استفاده می‌کنیم (فصل ۲۲ عمیق می‌شود):</p>
<div class="code"><div class="code-head"><span class="dots"><i></i><i></i><i></i></span><span class="fname">قالب</span></div><pre>type(scope): summary

بدنهٔ اختیاری — چرا، نه چه.
</pre></div>
<p class="keep-next">انواع رایج: <code>feat</code>، <code>fix</code>، <code>docs</code>، <code>chore</code>، <code>refactor</code>، <code>test</code>، <code>ci</code>.</p>
<div class="cols">
<div class="col good"><div class="col-title">خوب</div>
<p><code>feat(auth): add refresh-token rotation</code></p>
<p>چرا: نوع + محدوده + فعل امری + نتیجه.</p>
</div>
<div class="col bad"><div class="col-title">بد</div>
<p><code>update</code> یا <code>fix bug</code> یا <code>asdf</code></p>
<p>تاریخچهٔ بی‌معنی، <code>git log</code> را به زباله‌دان تبدیل می‌کند.</p>
</div>
</div>
<p>در VS Code پیام را در جعبهٔ بالا می‌نویسی. <code>Ctrl+Enter</code> کامیت می‌کند. اگر <em>Smart Commit</em> روشن باشد و چیزی stage نشده باشد، همه چیز را قورت می‌دهد — در فصل ۲ آن را خاموش کردیم.</p>

</div>

<p><strong>Senior — تفاوت <code>git log -p</code> و <code>git show</code>؟</strong> <code>show</code> یک شیء را نمایش می‌دهد؛ <code>log -p</code> پیمایش تاریخچه با diff هر کامیت است.</p>
