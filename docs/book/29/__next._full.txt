<h2><span class="hx"><span class="hx-t">🚫 اشتباههای زنجیره</span></span></h2>
<ul>
<li>اکشن <code>uses: some-user/action@main</code> — شاخه متحرک = کد متحرک</li>
<li><code>curl | bash</code> در CI</li>
<li>npm package typosquatting</li>
<li>خود-hosted runner روی ریپوی عمومی (fork می‌تواند کد اجرا کند)</li>
</ul>
<div class="callout callout-interview"><div class="callout-title">سؤالات مصاحبه (با پاسخ)</div>
<p><strong>Mid — push protection چیست؟</strong> سرور push را رد می‌کند اگر secret شناخته‌شده در diff باشد.</p>
<p><strong>Senior — attestation چه تضمینی است؟</strong> امضای GitHub روی metadata ساخت: workflow، SHA، هویت. Tamper بعد از ساخت را نشان می‌دهد؛ باگ منطقی داخل کد را نه.</p>
