<p><code>echo ${{ secrets.X }}</code> در لاگ می‌آید مگر mask شود. حتی mask هم کامل نیست. secret را چاپ نکن.</p>
</div>
<h2><span class="hx"><span class="hx-t">🖥️ Actions در VS Code</span></span></h2>
<p>افزونهٔ GitHub Actions: workflowها، runها، لاگ. <code>gh run watch</code> در ترمینال یکپارچه. روی PR تب Checks همان نتیجه را نشان می‌دهد.</p>
<div class="callout callout-interview"><div class="callout-title">سؤالات مصاحبه (با پاسخ)</div>
<p><strong>Junior — runner چیست؟</strong> ماشین (GitHub-hosted یا self-hosted) که stepها را اجرا می‌کند.</p>
<p><strong>Mid — تفاوت pull_request و pull_request_target؟</strong> دومی در زمینهٔ base با secret اجرا می‌شود — خطرناک اگر checkout روی کد fork باشد.</p>
<p><strong>Senior — OIDC چه حمله‌ای را می‌بندد؟</strong> کلیدهای بلندمدت ذخیره‌شده در secrets که با log یا memory dump می‌لکد؛ همچنین چرخش دستی.</p>
</div>
