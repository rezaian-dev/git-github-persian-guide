5:T1ac4,<p class="lead">Hook اسکریپتی است که Git در لحظه‌های مشخص (مثلاً قبل از commit) اجرا می‌کند. اگر اسکریپت با خطا خارج شود، آن commit یا push انجام نمی‌شود.</p>
  <h2><span class="hx"><span class="hx-t">🎯 اهداف یادگیری</span></span></h2>
<ul>
<li>hook محلی را از hook سمت سرور جدا کنی</li>
<li>بدانی <code>.git/hooks</code> پوشیدنی نیست</li>
<li>Husky / pre-commit framework را برای تیم بچینی</li>
<li>محدودیت hook را بشناسی (قابل دور زدن است)</li>
</ul>
<h2><span class="hx"><span class="hx-t">🪝 Git hooks کجایند؟</span></span></h2>
<p class="keep-next"><code>.git/hooks/</code> نمونه‌های <code>*.sample</code> دارد. فعال‌سازی = حذف پسوند و اجرایی کردن.</p>
<div class="code"><div class="code-head"><span class="dots"><i></i><i></i><i></i></span><span class="fname">pre-commit ساده — تست‌شده</span></div><pre>cat<span style="color: #F8F8F2"> </span>&gt;<span style="color: #F8F8F2"> </span>.git/hooks/pre-commit<span style="color: #F8F8F2"> </span><span style="color: #E6DB74">&lt;&lt; &#39;EOF&#39;</span>
<span style="color: #E6DB74">#!/usr/bin/env bash</span>
<span style="color: #E6DB74">set -euo pipefail</span>
<span style="color: #E6DB74">files=$(git diff --cached --name-only || true)</span>
<span style="color: #E6DB74">if printf &#39;%s\n&#39; &quot;$files&quot; | grep -Eq &#39;(^|/)\.env$&#39;; then</span>
<span style="color: #E6DB74">  echo &quot;do not commit .env&quot; &gt;&amp;2</span>
<span style="color: #E6DB74">  exit 1</span>
<span style="color: #E6DB74">fi</span>
<span style="color: #E6DB74">exit 0</span>
<span style="color: #E6DB74">EOF</span>
chmod<span style="color: #F8F8F2"> </span>+x<span style="color: #F8F8F2"> </span>.git/hooks/pre-commit
</pre></div>
<div class="callout callout-warn"><div class="callout-title">`set -e` و grep</div>
<p>اگر بنویسی <code>echo &quot;$files&quot; | grep ... &amp;&amp; exit 1</code> بدون <code>if</code>، وقتی <code>.env</code> در stage نیست grep کد ۱ برمی‌گرداند و <code>set -e</code> کل هوک را شکست می‌دهد — یعنی هیچ کامیتی رد نمی‌شود. الگوی <code>if grep; then exit 1; fi</code> را استفاده کن.</p>
</div>
<p>مشکل: این فایل در مخزن نیست. همکار تو hook ندارد.</p>

<h2><span class="hx"><span class="hx-t">🛡️ سمت سرور</span></span></h2>
<p class="keep-next">Hook محلی با <code>--no-verify</code> دور زده می‌شود. برای قانون واقعی:</p>
<ul>
<li>Ruleset: Conventional؟ خیر — پیام را GitHub اجباری نمی‌کند مگر Status Check</li>
<li>Status Check: job <code>commitlint</code> روی PR</li>
<li>Push rules: جلوگیری از <code>--force</code> روی main</li>
<li>CodeQL / secret scanning</li>
</ul>
<div class="callout callout-warn"><div class="callout-title">--no-verify در عجله</div>
<p>برای hotfix وسوسه‌انگیز است. اگر لازم شد، در PR توضیح بده و CI را اجباری بگذار تا دروازهٔ دوم کار کند.</p>
</div>
<h2><span class="hx"><span class="hx-t">🔌 VS Code</span></span></h2>
<p>وظایف <code>lint-staged</code> هنگام Commit از UI هم اجرا می‌شوند چون همان <code>git commit</code> را صدا می‌زنند. اگر hook شکست بخورد، VS Code خطا را در Git Output نشان می‌دهد.</p>
<div class="callout callout-interview"><div class="callout-title">سؤالات مصاحبه (با پاسخ)</div>
<p><strong>Junior — hook را چطور به GitHub می‌فرستم؟</strong> نمی‌فرستی؛ نسخه را در ابزار تیمی (Husky) داخل ریپو می‌گذاری.</p>
<p><strong>Senior — server-side hook در GitHub؟</strong> GitHub.com hook سفارشی Git ندارد؛ از webhooks، Actions و Rulesets استفاده کن. GitHub Enterprise Server گاهی pre-receive دارد.</p>
</div>
