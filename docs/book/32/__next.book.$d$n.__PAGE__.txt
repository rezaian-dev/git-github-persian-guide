<p>در VS Code ۲۰۲۶ پنجرهٔ Agents: چند نشست، worktree جدا، دیف کنار چت. هر نشست Git هویت خودش را دارد — مثل همکار موازی.</p>
<h2><span class="hx"><span class="hx-t">⚖️ قانون طلایی انسان</span></span></h2>
<ol>
<li><strong>هرگز</strong> PR عامل را بدون خواندن diff ادغام نکن</li>
<li>Secret و مجوز را در دستورالعمل ببند</li>
<li>کامیت‌های عامل را squash کن اگر نویز است</li>
<li>تاریخچه باید برای انسان قابل‌خواندن بماند</li>
<li>Ruleset و CI برای عامل همان است که برای کارآموز</li>
</ol>
<div class="callout callout-danger"><div class="callout-title">عامل + `--no-verify` + force</div>
<p>اگر به عامل اجازهٔ push مستقیم به main بدهی، مدل ذهنی این کتاب را دور ریخته‌ای. عامل هم باید از PR رد شود.</p>
</div>

<p><strong>Senior — مسئولیت حقوقی کامیت AI؟</strong> نویسنده/Approveکننده انسان است. امضا، review و attestation هنوز روی آدم است.</p>
</div>
