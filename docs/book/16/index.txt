1a:T1a37,<p class="lead">Clone = کپی مخزن روی رایانهٔ تو (با تاریخچه). Fork = کپی مخزن زیر حساب GitHub خودت. PR را باید از fork خودت به مخزن اصلی بفرستی؛ اگر فقط clone کرده باشی و حق push نداشته باشی، PR ساخته نمی‌شود.</p>
  <h2><span class="hx"><span class="hx-t">🎯 اهداف یادگیری</span></span></h2>
<ul>
<li>clone را با عمق و فیلتر درست انجام دهی</li>
<li>fork را با <code>origin</code> و <code>upstream</code> بچینی</li>
<li>شاخه را به‌روز نگه داری تا PR تمیز بماند</li>
</ul>
<h2><span class="hx"><span class="hx-t">📥 clone</span></span></h2>
<div class="code"><div class="code-head"><span class="dots"><i></i><i></i><i></i></span><span class="fname">clone هوشمند</span></div><pre>git<span style="color: #F8F8F2"> </span>clone<span style="color: #F8F8F2"> </span>git@github.com:rezaian-dev/javascript-persian-guide.git
git<span style="color: #F8F8F2"> </span>clone<span style="color: #F8F8F2"> </span>--depth<span style="color: #F8F8F2"> </span><span style="color: #AE81FF">1</span><span style="color: #F8F8F2"> </span>&lt;url&gt;<span style="color: #F8F8F2">              </span><span style="color: #959077"># فقط نوک — سریع، تاریخچه ناقص</span>
git<span style="color: #F8F8F2"> </span>clone<span style="color: #F8F8F2"> </span>--filter<span style="color: #FF4689">=</span>blob:none<span style="color: #F8F8F2"> </span>&lt;url&gt;<span style="color: #F8F8F2">     </span><span style="color: #959077"># partial؛ blob تنبل</span>
gh<span style="color: #F8F8F2"> </span>repo<span style="color: #F8F8F2"> </span>clone<span style="color: #F8F8F2"> </span>rezaian-dev/javascript-persian-guide
</pre></div>
<div class="cols">
<div class="col"><div class="col-title">🖥️ VS Code + GitHub</div>
<ol>
<li>Palette: <code>Git: Clone</code> یا Welcome → <em>Clone Git Repository</em></li>
<li>اگر افزونهٔ <strong>GitHub Pull Requests</strong> وصل است: <em>Clone from GitHub</em> و لیست ریپوهایت</li>
<li>پوشه را انتخاب کن → <em>Open</em></li>
<li>Fork از Command Palette: <code>GitHub Pull Requests: Fork</code></li>
</ol>
</div>
<div class="col"><div class="col-title">⌨️ Terminal</div>
<p><code>git clone git@github.com:org/repo.git</code>
<code>gh repo clone org/repo</code>
<code>gh repo fork org/repo --clone</code></p>
</div>
</div>
<div class="callout callout-warn"><div class="callout-title">depth 1 و بعدش</div>
<p>shallow clone برای CI عالی است. برای کار روزانه <code>bisect</code> و <code>blame</code> را ضعیف می‌کند. با <code>git fetch --unshallow</code> کاملش کن.</p>
</div>
<h2><span class="hx"><span class="hx-t">🍴 Fork — مدل مشارکت OSS</span></span></h2>
<div class="code"><div class="code-head"><span class="dots"><i></i><i></i><i></i></span><span class="fname">چیدمان استاندارد</span></div><pre>gh<span style="color: #F8F8F2"> </span>repo<span style="color: #F8F8F2"> </span>fork<span style="color: #F8F8F2"> </span>rezaian-dev/javascript-persian-guide<span style="color: #F8F8F2"> </span>--clone<span style="color: #FF4689">=</span><span style="color: #F8F8F2">true</span>
<span style="color: #F8F8F2">cd </span>javascript-persian-guide
git<span style="color: #F8F8F2"> </span>remote<span style="color: #F8F8F2"> </span>-v
<span style="color: #959077"># origin    تو (fork)</span>
<span style="color: #959077"># upstream  ریپوی اصلی</span>

git<span style="color: #F8F8F2"> </span>fetch<span style="color: #F8F8F2"> </span>upstream

<p class="keep-next">قانون طلایی:</p>
<ul>
<li><strong>origin</strong> = ریپوی تو (حق push)</li>
<li><strong>upstream</strong> = ریپوی صاحب پروژه (معمولاً read-only)</li>
<li>PR از <code>origin/feat/x</code> به <code>upstream/main</code></li>
</ul>
<p>در GitHub دکمهٔ <em>Sync fork</em> همین merge را گرافیکی می‌کند. در VS Code افزونهٔ PR ریموت‌ها را می‌شناسد.</p>
<h2><span class="hx"><span class="hx-t">🔁 مشارکت بدون fork — مدل تیمی</span></span></h2>
<p class="keep-next">در سازمان، معمولاً مستقیم روی ریپو دسترسی <code>write</code> داری:</p>
<div class="code"><div class="code-head"><span class="dots"><i></i><i></i><i></i></span><span class="fname">شاخه روی origin</span></div><pre>git<span style="color: #F8F8F2"> </span>switch<span style="color: #F8F8F2"> </span>-c<span style="color: #F8F8F2"> </span>feat/docs<span style="color: #F8F8F2"> </span>origin/main

gh<span style="color: #F8F8F2"> </span>pr<span style="color: #F8F8F2"> </span>create<span style="color: #F8F8F2"> </span>--base<span style="color: #F8F8F2"> </span>main
</pre></div>
<p>Fork برای OSS و پیمانکار خارجی است؛ برای همکار تمام‌وقت گام اضافه است.</p>
<div class="callout callout-interview"><div class="callout-title">سؤالات مصاحبه (با پاسخ)</div>
<p><strong>Junior — فرق clone و download ZIP؟</strong> ZIP بدون <code>.git</code> است؛ تاریخچه و شاخه ندارد.</p>
<p><strong>Mid — چرا دو remote؟</strong> تا بتوانی از upstream بگیر و به origin هل بدهی بدون حق نوشتن روی اصلی.</p>
<p><strong>Senior — fork network چیست؟</strong> گراف ریپوهای مشتق‌شده؛ GitHub objectها را تا حدی به اشتراک می‌گذارد. حذف fork تاریخچهٔ PR را پیچیده می‌کند.</p>
</div>
