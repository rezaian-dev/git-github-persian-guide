1a:T1ce5,<p class="lead">Remote فقط یک نام برای آدرس مخزن روی سرور است (معمولاً <code>origin</code>). Tracking یعنی شاخهٔ محلی تو به کدام شاخهٔ سرور وصل است — از روی آن Git می‌گوید چند کامیت جلوتر یا عقب‌تری.</p>
  <h2><span class="hx"><span class="hx-t">🎯 اهداف یادگیری</span></span></h2>
<ul>
<li><code>origin</code> را به‌عنوان نام مستعار URL توضیح دهی</li>
<li>fetch را از pull جدا کنی</li>
<li><code>-u</code> و شاخهٔ بالادست را تنظیم کنی</li>
<li>force-with-lease را به‌جای force خام استفاده کنی</li>
</ul>
<h2><span class="hx"><span class="hx-t">🌐 Remote چیست؟</span></span></h2>
<div class="code"><div class="code-head"><span class="dots"><i></i><i></i><i></i></span><span class="fname">دیدن و ساختن</span></div><pre>git<span style="color: #F8F8F2"> </span>remote<span style="color: #F8F8F2"> </span>-v
<span style="color: #959077"># origin  git@github.com:rezaian-dev/git-lab.git (fetch)</span>
<span style="color: #959077"># origin  git@github.com:rezaian-dev/git-lab.git (push)</span>

git<span style="color: #F8F8F2"> </span>remote<span style="color: #F8F8F2"> </span>add<span style="color: #F8F8F2"> </span>origin<span style="color: #F8F8F2"> </span>git@github.com:rezaian-dev/git-lab.git
git<span style="color: #F8F8F2"> </span>remote<span style="color: #F8F8F2"> </span>set-url<span style="color: #F8F8F2"> </span>origin<span style="color: #F8F8F2"> </span>git@github.com:rezaian-dev/git-lab.git
</pre></div>
<p>در VS Code: <em>Publish Branch</em> اگر origin نباشد، ویزارد GitHub را باز می‌کند.</p>
<h2><span class="hx"><span class="hx-t">📡 fetch ≠ pull</span></span></h2>
<div class="tbl-wrap"><table><thead>
<tr>
<th>فرمان</th>
<th>چه می‌کند</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>git fetch</code></td>
<td>اشیای جدید را می‌آورد؛ شاخهٔ محلی را حرکت نمی‌دهد</td>
</tr>
<tr>
<td><code>git fetch --prune</code></td>
<td>refهای حذف‌شده روی سرور را محلی پاک می‌کند</td>
</tr>
<tr>
<td><code>git pull</code></td>
<td><code>fetch</code> + <code>merge</code> (یا rebase اگر تنظیم شده)</td>
</tr>
<tr>
<td><code>git pull --ff-only</code></td>
<td>فقط اگر fast-forward ممکن باشد — امن‌ترین pull</td>
</tr>
</tbody>

git<span style="color: #F8F8F2"> </span>log<span style="color: #F8F8F2"> </span>--oneline<span style="color: #F8F8F2"> </span>HEAD..origin/main<span style="color: #F8F8F2">    </span><span style="color: #959077"># چه چیزی می‌آید؟</span>

</ul>

<code>git pull --ff-only</code>
<code>git push -u origin HEAD</code></p>

<h2><span class="hx"><span class="hx-t">📌 tracking</span></span></h2>
<div class="code"><div class="code-head"><span class="dots"><i></i><i></i><i></i></span><span class="fname">بالادست</span></div><pre>git<span style="color: #F8F8F2"> </span>switch<span style="color: #F8F8F2"> </span>-c<span style="color: #F8F8F2"> </span>feat/auth
git<span style="color: #F8F8F2"> </span>push<span style="color: #F8F8F2"> </span>-u<span style="color: #F8F8F2"> </span>origin<span style="color: #F8F8F2"> </span>HEAD<span style="color: #F8F8F2">          </span><span style="color: #959077"># -u = --set-upstream</span>
git<span style="color: #F8F8F2"> </span>status<span style="color: #F8F8F2"> </span>-sb
<span style="color: #959077"># ## feat/auth...origin/feat/auth [ahead 1, behind 2]</span>
</pre></div>
<ul>
<li><strong>ahead</strong> = کامیت محلی که remote ندارد</li>
<li><strong>behind</strong> = کامیت remote که محلی نداری</li>
<li>هر دو = واگرایی → باید merge یا rebase کنی قبل از push</li>
</ul>
<h2><span class="hx"><span class="hx-t">🚀 push امن</span></span></h2>
<div class="code"><div class="code-head"><span class="dots"><i></i><i></i><i></i></span><span class="fname">هرگز --force خام روی شاخهٔ مشترک</span></div><pre>git<span style="color: #F8F8F2"> </span>push<span style="color: #F8F8F2"> </span>--force-with-lease
<span style="color: #959077"># اگر کس دیگری push کرده باشد، رد می‌شود</span>
</pre></div>
<p><code>--force</code> کورکورانه تاریخچهٔ سرور را عوض می‌کند. <code>--force-with-lease</code> فقط اگر remote همان چیزی باشد که تو آخرین‌بار دیدی.</p>
<p>در VS Code هنگام Push اگر rejected شدی، <em>Force Push</em> را نزن مگر روی شاخهٔ شخصی.</p>
<div class="callout callout-danger"><div class="callout-title">--force روی main</div>
<p>در Rulesets باید ممنوع باشد. اگر نیست، همین امروز ممنوعش کن (فصل ۲۷).</p>
</div>
<div class="callout callout-interview"><div class="callout-title">سؤالات مصاحبه (با پاسخ)</div>
<p><strong>Junior — origin اسم خاصی است؟</strong> قرارداد است؛ می‌تواند <code>github</code> باشد. فقط نام مستعار URL است.</p>
<p><strong>Mid — چرا ff-only؟</strong> جلوی mergeهای اتفاقی و تاریخچهٔ دندانه‌دار را می‌گیرد.</p>
<p><strong>Senior — lease چه چیزی را می‌سنجد؟</strong> هش <code>refs/heads/...</code> روی remote را با remote-tracking محلی مقایسه می‌کند.</p>
</div>

<li>force خام را کنار گذاشته‌ای</li>
</ul>
